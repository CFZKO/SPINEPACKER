Tray size

Artwork CSV

No header row. 5 columns in order: Tray, Height, Length, Thickness, Ref #
Tray is the tray number you assign each piece to (1, 2, 3…). Multiple rows can share a tray number — the tray holds all of them side by side.
Ref # is your artwork reference number — it's shown on the artwork rectangle in each tray's diagram.
Pad model (from your diagram):
Artwork registers to the bottom of the tray (gravity), centered/grouped side to side. Pads are always the width set above — only their reach varies.
The spine — the pads' position (not length) is fixed for every tray, set once by the smallest height and smallest length found anywhere in the CSV.
Vertical pads — for a tray holding a single artwork, both edges sit at the spine's fixed side position. For a tray holding more than one artwork, the true outer edges (touching the tray wall side) are tertiary instead — it's the inner edges, facing across the gap between artworks, that use the spine's fixed reference. These stay labeled "Vertical Pad."
Tertiary pads — touch that artwork's own actual edge directly and aren't spine-anchored. Shown in a different color and listed separately.
Pad depth — every pad in a tray uses that tray's greatest artwork thickness plus 1/8", even for pads touching a thinner piece. The thinner piece gets shimmed at the back to sit flush.
Horizontal pads (qty 4 per tray — top pair at the spine's fixed height, bottom pair at the tray floor) — reach sideways from the wall to the group's outer artwork edge.
I've labeled these by orientation rather than the guide's "A/B" since that mapping wasn't fully clear from the text — flag it if you'd rather see A/B labels instead.
